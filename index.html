Report Extraction

Pure browser app: PDF / MSG / ZIP → review → update Excel → download.

Local file processing · No third-party requests

1. Load an existing Excel workbook (optional)

Skip this step to create a brand-new Excel workbook. If selected, your workbook is read locally by your browser.

2. Add complaint files

Select multiple files at once or add more files later. A repeated complaint updates its existing row; a different complaint is added.

3. Review extracted information

Each complaint occupies one complete row. Use the three tabs to move from case overview to investigation details and test evidence.

Lots in current results

This table summarizes the reviewed complaints currently waiting for Excel export.

4. Check existing lot history

Counts unique complaints from the same lot and shows how often each symptom theme was reported.

5. Create or update Excel

One complaint number remains one row. Multiple MR / FR values remain together in one cell. Without an uploaded workbook, a new Excel file is created. Product-family sheets are rebuilt from all three categories, the three organized review tabs are written to separate worksheets, detailed assays are written to Extracted Test Evidence, and lot/symptom counts are written to Lot & Symptom Summary.

Workbook Summary

Choose one or more Excel workbooks and report files, then build one searchable complaint list from all relevant worksheets and reports. Current extracted reports are included automatically. Everything stays in this browser.

Choose information to list

Tick only the columns you want to see. Complaint counts are calculated from unique complaint numbers for each lot.

Quick Search

Find a lot or complaint

Choose lot or complaint, select a product family if needed, then choose a number. Every number also shows its associated customer.

Find a customer complaint

Choose in this order: customer → membrane type → complaint number. The result includes the related lot and full complaint information.

Find similar symptoms and historical tests

Choose a membrane family and a reported symptom to find related complaint cases, lots, tests performed and final results.
